# VAANI

A lightweight, static English-learning workspace for NDA aspirants. It combines grammar, vocabulary, comparisons, previous-year questions, practice, and a personal book-reading library.

## Open the app

Visit **https://harshiiiit-bh.github.io/vaani/**. The site is hosted on GitHub Pages; no build step or package installation is required.

## Main areas

- **Dashboard:** learning progress, daily activity, and focus tools.
- **Grammar & Comparisons:** concise lessons and practice.
- **Vocabulary:** searchable word bank, examples, and exam-oriented drills.
- **Book Reading:** personal book library, reading logs, highlights, a vocabulary register, level checks, and spoken-English practice.
- **Previous Year Questions & Arena:** exam practice and interactive challenges.
- **Leaderboard & Profile:** progress and account details.

## Book Reading vocabulary

While reading, enter a word, idiom, or phrase and choose **Add with meaning** for the guided dictionary flow. For a faster capture, select text on the book detail page and choose **Capture selection**, or use **Quick-add typed text**. Captures appear in the Book Reading **Vocab Register** and retain their source book.

The main Vocabulary area links directly to that register.

## Data and privacy

VAANI is a static website. On GitHub Pages, account codes identify locally saved profiles in the current browser; they do not provide cross-device synchronization. Keep a backup from the app's settings if you need to move your reading data. Do not put passwords, API keys, or other secrets in this repository.

## Project layout

- `index.html` — app shell and main interface.
- `styles*.css`, `vaani-*.css` — visual styling.
- `js/library.js` — Book Reading features and its data handling.
- `data/` — grammar, vocabulary, PYQ, and reading-support data.
- `assets/` — images used by the site.

Keep the relative folder structure intact when deploying.
